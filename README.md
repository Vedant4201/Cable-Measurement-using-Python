# Cable-Tension-Measurement-using-Python
Cable Tension Measurement System (CTMS) is used to measure and monitor the tension in a Fibre Optic Towed Cable (FOTC) in marine applicaations. Tension in the cable is transferred through the pulleys, and the spring deflection, due to the increased load is further recorded by the load cell. Target is to estimate spring stiffness which is an important aspect of the CTMS project. The maximum load experienced by the cable is around 65 kN and the maximum deflection it should undergo is around 2.5 mm.
Following three graphs were required to plot to analyze the spring behavior wrt varying loads:
1. Cable Tension vs. Deflection
2. Cable Tension vs. Load on Spring
3. Cable Tension vs. Change in angle
Code is written in python to estimate the spring stiffness based on the physics of spring non-linearity.
